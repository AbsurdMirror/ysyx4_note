  ```bash
  cat /usr/share/dict/words
  | tr "[:upper:]" "[:lower:]"

  | grep -v "'s$"
  ```

- [3] 进行原地替换听上去很有诱惑力，但是这并不是一个明智的做法，为什么呢？
  - 在IO重定向中，shell会先将标准输出和标准错误输出准备好，然后读取标准输入。因此对于命令 `cat < abc.txt > abc.txt` ，shell会先将abc.txt清空，然后读取abc.txt（读出空内容），再写入abc.txt。
  - 参考链接：[shell十三问-11)>與<差在哪](http://bbs.chinaunix.net/forum.php?mod=viewthread&tid=218853&page=7#pid1636825)
  - 存疑：执行命令`cat <> abc.txt`，表现：命令行界面输出 `abc.txt` 的内容，`abc.txt`文件内容不变。其执行原理是什么?

- [4] 找出您最近十次开机的开机时间平均数、中位数和最长时间

  ```bash
  # 平均数
  journalctl | grep "Startup finished in" | grep "systemd\[1\]"
  | sed -E "s/.*=\ (.*)s\.$/\1/"
  | paste -sd+ | bc | awk '{print $1/10}'

  # 中位数
  journalctl | grep "Startup finished in" | grep "systemd\[1\]"
  | sed -E "s/.*=\ (.*)s\.$/\1/"
  | sort | paste -sd\  | awk '{print ($5+$6)/2}'

  # 最长时间
  journalctl | grep "Startup finished in" | grep "systemd\[1\]"
  | sed -E "s/.*=\ (.*)s\.$/\1/"
  | sort | tail -n1
  ```
