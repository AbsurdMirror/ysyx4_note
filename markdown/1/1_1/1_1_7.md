# 1.1.7 调试及性能分析

## 视频笔记

- 调试方法
  - 打印与日志
    - 打印输出或记录到日志
    - 终端使用彩色打印
    - 配置、查阅第三方软件的日志系统
    - 系统日志
    - 对日志进行数据整理或使用工具更舒适地查阅
  - 调试器
    - python的调试器：`pdb` `ipdb`
    - C/C++的调试器：`gdb` `pwndbg` `lldb`
  - 其他专用工具
    - `strace`: 追踪系统调用
    - `tcpdump` `wireshark`: 网络数据包分析工具
    - 浏览器开发者工具: web开发
    - 静态分析工具
      - python的静态分析工具：`pyflakes`
      - shell的静态分析工具：`shellcheck`
    - 编辑器和IDE的 code linting 插件或功能
    - 代码风格或格式检测

- 性能分析方法和工具
  - 计时分析
    - 编程语言的计时功能
    - linux的 `time` 命令
  - 性能分析
    - CPU
      - 追踪分析器（tracing）及采样分析器（sampling）
      - 大多数的编程语言都有一些基于命令行的分析器
      - python: `cProfile` `line profiler`
    - 内存
      - C/C++: `Valgrind`
      - python: `memory-profiler`
    - 事件分析
      - 报告与您的程序相关的系统事件
      - linux `pref` 命令
    - 可视化
      - CPU 分析数据：`Flame Graphs`
      - python的调用图： `pycallgraph`
  - 资源监控
    - 通用监控 `htop`
    - I/O操作 `iotop`
    - 磁盘使用 `df` `du`
    - 内存使用 `free`
    - 文件占用 `lsof`
    - 网络占用 `ss` `nethogs` `iftop`
  - 其他专用工具
    - 程序性能比较  `hyperfine`
    - 浏览器的debug功能
