# 3.1.2 穿越时空的旅程

## 异常响应机制

|特殊的原因? (建议二周目思考)|
|:-|
|**Q:** 这些程序状态(x86的eflags, cs, eip; mips32的epc, status, cause; riscv32的mepc, mstatus, mcause)必须由硬件来保存吗? 能否通过软件来保存? 为什么?|
|**A:** 必须由硬件来保存，不能由软件来保存，异常出现时需要立即记录异常信息以实现精确异常，同时大部分异常都是某条指令携带的，指令引起的异常必须在该指令执行过程记录信息，无法等到软件再使用下一条指令处理。更重要的是异常出现是不可预测的，软件很难即使检测和处理|
