# 2.1.3 实现更多调试功能

在后面的学习过程中，为了方便调试，给调试器添加了一些功能，也增加了几个make命令。在此一并整理。

## 调试器添加 `restart` 命令

使用nemu运行调试am程序时，程序出错后想倒回去调试的话只能输入q命令退出程序，然后重启。因此考虑实现一个重启命令让nemu重新开始运行am程序。

从 `nemu-main.c` 文件中可以找到nemu在启动调试功能之前做了哪些工作，重启执行的工作就从这里筛选。

此外还需要在最后加一步：把 `nemu.state` 的值改一下。

[查看代码](https://github.com/AbsurdMirror/ysyx4-workbench/commit/955a9a9fe67f1dc851541907d15d9ecf7156af85)

## 调试器添加查看pc值的功能

在调试时发现有查看客户机的pc值的需求。对调试器做出如下修改：

- 给 `info` 命令添加一个 `p` 参数，`info p` 命令就可打印出pc值
- 表达式功能支持 `$pc` ，与寄存器类似，`$pc` 即代表pc值。

[查看代码](https://github.com/AbsurdMirror/ysyx4-workbench/commit/96a5d1d095bcb436f6c7ea94b34e68d8e1dca093)

[查看代码](https://github.com/AbsurdMirror/ysyx4-workbench/commit/01efef8329e9239b077330ae2e42d5ded71c730f)

## make添加代码计数功能

为了方便统计新增代码行数添加了代码计数功能。

### 使用方法

```sh
# 该命令可统计当前C代码和其他分支的C代码行数，并计算增加量 (或许是个负值？？？)
# COUNT_REF 变量为对比的分支，默认值为pa0
make count COUNT_REF=...
```

### 实现方法

此次不记录详细实现，只列出涉及到的知识点。

- `git stash` ： 可将未被git记录的代码保存，用法
  - `git stash apply`
  - `git stash list`
- `git symbolic-ref` ：可用该命令获取当前分支名（跳过去总得再跳回来吧）
- `wc` ： 可打印文件大小，包括行数、字节数等

还有一件事（老爹）：如果想让git跟踪sh脚本，记得修改 `.gitignore`

[查看代码](https://github.com/AbsurdMirror/ysyx4-workbench/commit/ac84d9efd9b99dbecf64b9ed4287d6a79dadcd43)

## make添加生成预编译结果功能

nemu中的宏定义太多了，预编译可将代码中的宏展开，方便代码的阅读。

### 使用方法

```sh
make precom
```

### 实现方法

`gcc -E` 可输出代码的预编译结果，更多的工作是要读懂makefile，获取需要添加的include目录。

[查看代码](https://github.com/AbsurdMirror/ysyx4-workbench/commit/e6c5bd760d2943d1991d0e59ed6cac38dad53c9a)

### 更好的实现

由于给每个C文件都引入全部的宏定义，导致生成的预编译代码前面很大一部分代码都是无关的定义。（源代码不到100行，预编译代码7000多行，这河里吗？）

考虑对预编译输出处理，截取最后和源代码相关的部分。
