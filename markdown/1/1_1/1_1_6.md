## 课后练习

- [1] 如果您之前从来没有用过 Git，推荐您阅读 Pro Git 的前几章，或者完成像 Learn Git Branching这样的教程。
  - *未做*

- [2] Fork 本课程网站的仓库
  - [1] 将版本历史可视化并进行探索

    ```bash
    git log --all --graph --decorate
    ```

  - [2] 是谁最后修改了 README.md文件？（提示：使用 git log 命令并添加合适的参数）

    ```bash
    git log README.md
    ```

  - [3] 最后一次修改_config.yml 文件中 collections: 行时的提交信息是什么？（提示：使用 git blame 和 git show）

    ```bash
    git blame _config.yml | grep collections
    # a88b4eac (Anish Athalye 2020-01-17 15:26:30 -0500 18) collections:

    git show a88b

    # 进入vim模式显示 a88b4eac 的提交内容，使用vim的搜索功能
    /collections
    ```

- [3] 尝试向仓库中添加一个文件并添加提交信息，然后将其从历史中删除

  ```bash
  echo "abc" > abc.txt
  git add abc.txt
  git commit -m "add abc.txt"
  ls
  git log --all --oneline | head -5

  pip install --user git-filter-repo
  git filter-repo --force --invert-paths --path abc.txt
  ls
  git log --all --oneline | head -5
  ```

- [4] 从 GitHub 上克隆某个仓库，修改一些文件。当您使用 git stash 会发生什么？当您执行 git log --all --oneline 时会显示什么？

  ```bash
  git log --all --oneline | head -4
  # 488e636 Merge pull request #187 from HtwoO/patch-1
  # 90fe0de private key path is expected after -i of ssh client
  # 9837d16 Merge branch 'soulrrrrr/soulr'
  # d8991dc Add <br> at the 'About the class' section. The 'Questions' title will move to the next line.
  git stash
  # Saved working directory and index state WIP on master: 488e636 Merge pull request #187 from HtwoO/patch-1
  git log --all --oneline | head -4
  # b70bf6c WIP on master: 488e636 Merge pull request #187 from HtwoO/patch-1
  # 123ca36 index on master: 488e636 Merge pull request #187 from HtwoO/patch-1
  # 488e636 Merge pull request #187 from HtwoO/patch-1
  # 90fe0de private key path is expected after -i of ssh client
  git stash pop
  # On branch master
  # Your branch is up to date with 'origin/master'.
  # ...
  git log --all --oneline | head -4
  # 488e636 Merge pull request #187 from HtwoO/patch-1
  # 90fe0de private key path is expected after -i of ssh client
  # 9837d16 Merge branch 'soulrrrrr/soulr'
  # d8991dc Add <br> at the 'About the class' section. The 'Questions' title will move to the next line.
  ```

- [5] 请在 ~/.gitconfig 中创建一个别名

  ```bash
  [alias]
    graph = log --all --graph --decorate --oneline
  ```
