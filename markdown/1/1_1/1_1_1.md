# 1.1.1 课程概览与shell

## 视频笔记

本节先简要讲述了课程安排和shell的概念，后重点讲述了shell的基本用法。我在学习之前已对shell有简单的了解，以下重点记录了学习到的新内容。

- 一个参数中存在空格怎么办：如果直接把参数输入则会被识别为两个参数，例如 `echo hello world` 。解决方法：
  - 可以使用引号，单引号或双引号都可，例如 `echo "hello world"` 。
  - 可以使用转义符号，例如 `echo hello\ world` 。

- `man` 命令：可以用该命令查阅命令的使用说明，例如 `man ls` 。

- `cat` 命令：可以用该命令读取文件内容并输出，例如 `cat README.md` 。

- 重定向命令：可以用 `< file` 和 `> file` 命令重定向输入输出流；可以用 `>> file` 向文件追加内容；可以用 `|` 操作符将左边的输出传输为右边的输入。例如：

  ```bash
  echo "/home" > test.txt
  cd < test.txt
  echo "/bin" >> test.txt
  cat test.txt
  cat test.txt | tail -n1
  ```

- sudo命令：可以以超级管理员的身份执行后面的命令 ；可以用 `sudo su` 命令切换为root用户；可以用 `exit` 命令退出root用户。例如：

  ```bash
  cd /sys/class/leds/input1::capslock

  # 以下两条命令会报错提示"Permission denied"
  sudo echo 0 > brightness
  echo 0 > sudo brightness

  # 直接用sudo命令
  echo 0 | sudo tee brightness

  # 切换root用户操作
  sudo su
  echo 1 > brightness
  exit
  ```

## 课后练习

- 1. 操作系统配置:使用Linux虚拟机
  - 虚拟机软件：VMware
  - Linux版本：Ubuntu 20.04.3

- 2. 在 /tmp 下新建一个名为 missing 的文件夹。

  ```bash
  cd /tmp
  mkdir missing
  ```

- 3. 用 man 查看程序 touch 的使用手册。

  ```bash
  man touch
  ```

- 4. 用 touch 在 missing 文件夹中新建一个叫 semester 的文件。

  ```bash
  touch semester
  ```

- 5. 将内容一行一行地写入 semester 文件。

  ```bash
  echo -e "\x23\x21/bin/sh" >> semester
  echo  "curl --head --silent https://missing.csail.mit.edu" >> semester
  ```

- 6. 尝试执行这个文件。

  ```bash
  ./semester
  # bash: ./semester: Permission denied
  ls -l
  #-rw-rw-r-- 1 dzx dzx 61 Mar  3 19:01 semester
  ```

  无法执行的原因：使用ls命令可以看到，semester没有执行权限，因此无法执行。

- 7. 查看 chmod 的手册

  ```bash
  man chmod
  ```

- 8. 使用 chmod 命令改变权限，使 ./semester 能够成功执行。

  ```bash
  chmod -c 777 ./semester
  ./semester
  # ./semester: 2: curl: not found
  sudo apt-get install curl
  ./semester
  ```

- 9. 使用 | 和 > ，将 semester 文件输出的最后更改日期信息，写入主目录下的 last-modified.txt 的文件中。

  ```bash
  ./semester | grep -i last-modified | cut -d ' ' -f 2,3,4,5,6,7 > ~/last-modified.txt
  ```

- 10. 写一段命令来从 /sys 中获取笔记本的电量信息，或者台式机 CPU 的温度。注意：macOS 并没有 sysfs，所以 Mac 用户可以跳过这一题。

  ```bash
  # 虚拟机中无法查看电量和温度，尝试查看数字小键盘是否启用
  cd /sys/class/leds
  cd input1::numlock
  ls
  # brightness  device  max_brightness  power  subsystem  trigger  uevent
  cat brightness
  # 1
  ```

  brightness为1表示数字小键盘启用；为0表示数字小键盘未启用。

## 小插曲

在练习sudo命令时发现我的ubuntu系统中 `sys/class/backlight` 文件夹下 `brightness` 没有文件,也就是说无法通过这种方法调整屏幕亮度。经过搜索得知这是因为我的ubuntu系统为虚拟机系统。后来又尝试了 `xrandr` 命令，虽然`brightness`的值修改了，但屏幕亮度无变化。
