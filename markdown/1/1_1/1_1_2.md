# 1.1.2 Shell工具和脚本

## 视频笔记

### shell脚本

- 常用语法
  - `foo=bar` 而不是 `floo = bar`
  - `echo "$foo"` 和 `echo '$foo'` 的区别
  - 函数定义 `abc () { mkdir "$1" }`
  - 加载函数到shell中： `source abc.sh`
  - 常见保留变量：
    - `$0` 脚本名
    - `$1` ~ `$9` 输入参数
    - `$?` 上一个命令的返回值
    - `$#` 参数个数
    - `$@` 所有参数
    - `$$` 进程码(PID)
    - `!!` 完整的上一条命令  (bang bang)
    - `$_` 上一条命令最后一个参数
  - 返回值: 0为成功执行，其他值均为错误执行
  - `false` `true` `||` `&&` 的用法
  - `$(pwd)`
  - `if`和`for`的用法
  - `/dev/null`的作用
  - `# 注释`
  - 通配符的使用
    - ls *.sh
    - ls project?
    - cp image.{png,jpg}   touch foo{1,2,3,4}_{a...j}
  - shebang的使用，如： `#!/usr/bin/env python`

- 工具
  - `test` 命令
  - `shellcheck`命令，如： `shellcheck abc.sh`
  - 命令使用说明：`man` \ `tidr`
  - 文件查找：`find` \ `fd` \ `locate`(`updatedb`)
  - 字符串查找：`grep` \ `rg` \ `ack` \ `ag`
  - 前面用过的命令查找：`history` \ `fzf`
  - shell界面工具：`fish` \ `zsh`
  - 文件目录结构：`tree` \ `broot` \ `nnn`
  - 目录切换：`cd` \ `autojump`

## 课后练习

- 1. 阅读 `man ls` ，然后使用 `ls` 命令进行操作

  ```bash
  man ls

  # 用tidr查看ls命令
  sudo apt-get install npm
  sudo npm install -g tldr
  tldr ls

  # 用ls执行操作
  # -a 显示全部
  # -lh 文件大小使用人类可读的格式
  # -ltr 根据修改日期排序
  # --color 显示颜色
  ls -a -lh -ltr --color
  ```

- 2. 编写两个bash函数 marco 和 polo 执行操作

  ```bash
  #!/bin/bash
  marco () { pwd > ~/workspace/s2.txt; }
  polo () { cd "$(cat ~/workspace/s2.txt)" || exit; }
  ```

- 3. 编写一段bash脚本，运行如下的脚本直到它出错

  ```bash
  #!/usr/bin/env bash

  rm -rf error_output.txt
  rm -rf error_err.txt

  res=0

  while [ $? -eq 0 ];
  do
    ((res++));
    bash error.sh >>error_output.txt 2>>error_err.txt;
  done;

  echo "run times: $res"
  ```

- 4. 编写一个命令，它可以递归地查找文件夹中所有的HTML文件，并将它们压缩成zip文件.

  ```bash
  find ./html/ -name '*.html' | xargs -d '\n' tar czf html.tar.gz
  ```

- 5. 编写一个命令或脚本递归的查找文件夹中最近使用的文件

  ```bash
  find . -type f | xargs -d '\n' ls -ltr
  ```
