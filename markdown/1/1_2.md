# 1.2 搭建verilator仿真环境

## 认识和安装verilator

verilator是一款开源的verilog仿真工具，它可以将verilog/SV代码综合成C++/SystemC代码，并仿真。

安装指定版本的verlator的过程:

```bash
  git clone https://github.com/verilator/verilator
  cd verilator/

  # 查看当前的提交位置和指定版本的hash号
  # 后续了解到checkout可以直接指定tag
  # git logl 是我自定义的别名，在我的dotfiles仓库中可查看
  git logl
  git checkout 8e2ba6a00382075387b32fbbf8f5f85fec482d9a
  git logl

  unset VERILATOR_ROOT

  # autoconf未安装，根据错误提示安装
  autoconf
  sudo apt install autoconf
  autoconf
  ./configure

  make -j `nproc`
  sudo make install

  # 安装成功，查看版本
  verilator --version
  # Verilator 4.210 2021-07-07 rev v4.210
```

## 示例: 双控开关

运行代码较为简单，此处重点记录verilator生成的C++代码。

- verilog中的 `module` 会被转换为C++的 `class` 。
- verilog代码中定义的输入、输出接口，均被转换为C++中的对应变量。

  |verilog|C++|
  |:--:|:--:|
  |input (wire)|VL_IN8|
  |output (wire)|vL_OUT8|

- 生成的C++类的主要的一个函数：eval()，查看它的实现，发现实现较为复杂，它最主要的功能就是完成 `f <= a ^ b` 的计算，最后找到了它的位置

  ```C++
    // filename: Vtop.h
    void eval() { eval_step(); }

    // filename: Vtop.cpp
    void Vtop::eval_step() {
      ... // 省略不必要代码
      Vtop___024root___eval(&(vlSymsp->TOP));
      ...
    }

    //filename: Vtop___024root.cpp
    void Vtop___024root___eval(Vtop___024root* vlSelf) {
        ...
        Vtop___024root___combo__TOP__1(vlSelf);
    }

    //filename: Vtop___024root.cpp
    VL_INLINE_OPT void Vtop___024root___combo__TOP__1(Vtop___024root* vlSelf) {
      ...
      // 这句代码就是 f <= a + b 的实现
      vlSelf->f = ((IData)(vlSelf->a) ^ (IData)(vlSelf->b));
    }
  ```

## 打印并查看波形

在手册中查找到生成波形的办法并操作，记录一下重点。

- 运行命令时添加 `--trace` 选项
- 代码中 *仿真开始前* 配置相关设置 `Verilated::traceEverOn(true)`
- 代码中 *仿真开始前* 创建 `VerilatedVcdC` 对象，设置跟踪层级和输出文件位置
- 代码中 *仿真过程中* 使用 `timeInc` 函数推进时间，使用 `dump` 函数记录波形
  - **注意**: **如果不使用 `timeInc` 函数，记录的波形的时间长度为0。** 因为仿真时间值一直没有推进，可使用 `time` 函数查看仿真时间值。
- 代码中 *仿真结束后* 使用 `close` 函数将 `VerilatedVcdC` 对象释放

## 示例: 流水灯

相比于双控开关，流水灯的实现多了时钟和复位信号。C++代码的改动较多，基本参考NVBoard的示例，仍然保留了波形记录功能。

对比双控开关，分析verilator生成的C++代码：

- verilog和C++的输入输出的对应关系如下表，对比双控开关，了解了 `VL_IN8(clk,0,0)` 函数中后两个参数的作用，即表示每一位(bit)的对应关系。

  |verilog|C++|
  |:--:|:--:|
  |input (wire)|VL_IN8(0,0)|
  |output (wire) [15:0] |VL_OUT16(15,0)|

- `eval()` 的实现中相比于双控开关，增加了对时钟跳变沿的判断，对应于verilog代码中的 `always @(posedge clk)` 。

  ```C++
    void Vtop___024root___eval(Vtop___024root* vlSelf) {
        ...
        // Body
        // if的执行：该时刻的clk为1且上一时刻的clk为0，即clk的上升跳变沿
        if (((IData)(vlSelf->clk) & (~ (IData)(vlSelf->__Vclklast__TOP__clk)))) {
            Vtop___024root___sequent__TOP__1(vlSelf);
        }
        // Final
        // 此处将本时刻的clk记录下来，用于下一时刻的clk判断
        vlSelf->__Vclklast__TOP__clk = vlSelf->clk;
    }
  ```
